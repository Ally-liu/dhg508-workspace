# Questions I want to keep track of

Running note of things I did not understand at first, and things that are still
unclear (Week 1, challenge 3).

## Answered along the way

- What is a fork, and why work in my own copy instead of the teacher's
  repository? — A fork is my own copy on github.com; I can change it freely,
  and the teacher can later see my work by looking at my fork.
- What is a URL? — The address of a page, like `https://github.com/Ally-liu/dhg508-workspace`.
- What are `origin` and `upstream`? — Two saved addresses: `origin` = my fork
  (I push there), `upstream` = the teacher's original (I only pull updates
  from there).
