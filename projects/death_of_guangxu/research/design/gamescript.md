# Game Script 《廿一来信》 v2 — 光绪之死 · 解密剧本（记者线）

## 一、形态与定位

- 单机线上剧本杀/解密游戏（浏览器内；主持人职能由游戏流程承担，
  "史先生"NPC 在场内但当查档与质询之责）。
- 一局 **30–45 分钟**（完整线，含全部任务与两张隐藏卡）。
- 底层资产全复用：55 行证据 / 6 组矛盾对 / verdict·annotation 表 /
  /api/ask 真模型对稿。

## 二、世界观（_epoch 锚定在真实日期）

> **癸丑年（1913）冬，北京。**
> 崇陵成，奉安在即，各大报馆派出人手赴西陵做"最后一独立标题"。
> 你是《申报》驻京的年轻记者。（奉安确切日期档房来函未定——
> 游戏中只说"冬天"，不硬编日期，守史料纪律。）
> 上头派你给头版：出殡之外，还得有点"人"——宫里那段公案，
> 从辛亥以前就没有公认的定论。
> 开场触发器：**一封匿名来信**，信只有一行——
> 　　"廿一小时。两宫同日。阅档房，问朱批。"

（匿名信是入局道具，非史料；规则第 §六 允许"道具级虚构"。）

## 三、角色册（NPC ×6 + 玩家）

每位 NPC 给**人设卡**：身份 / 说话方式 / 知道什么 / 拒绝什么 / 演绎信念感指标。

### 玩家
《申报》驻京记者（年轻，初到），手里一支笔、一册采访本、有限的版面。
**你不需要赢**——你的"成绩"就是你最后签发的那版稿子里是否把
每个 [id] 落地。开场你的记者视角：冲着大新闻来的，但写着写着
会被证据拖着走得越来越慢。

### 恽毓鼎（约 51 岁，起居注官，旧臣）
- 说话：文白相间，回避直问，引"亲闻亲见"；
- 知道：十月初十贺寿的全部细节 [E03/E04]、皇后发现帝崩的时序 [E09]；
- 拒绝：替君相背罪名（"此言臣不敢出"）；对"喜色"一词只肯说
  "闻者云云"；
- 关键：他**是"两副面孔"的原作者**——V01 与 D09 的碰撞从他口中
  才和你对上。

### 杜钟骏（江苏名医，光绪末曾奉召入诊，今仍悬壶）
- 说话：医家口吻，惜字如金；
- 知道：奉召前后的脉案口径 [D09]、他自己那句"不求有功但求无过"[D09 转述]；
- 拒绝：断言死因；谈起"利剂"[G04 力钧] 立即请茶送客；
- 隐藏卡**"塌喇"**从他的"太医院同僚"转述延出（限口径：仅闻）。

### 内务府旧人（耆存者父亲辈的口述者，借人立言）
- 说话：京片子，絮叨，带"咱们府里…"；
- 知道：入殓那夜谁在、礼臣被拒 [E11/E12]、遗诏之事的传闻 [V03]；
- 拒绝：指名道姓（"这话说不清啦"[D05 原话]）。

### 老太监（今已出宫，走街串巷）
- 说话：短句，警觉，先看门口再说话；
- 知道：太监净发昌言之说 [E07][E06]、"塌喇"盖碗的街面版本 [D06]；
- 拒绝：承认自己当时在场（"便衣混在杂役里，哪数得清"[E07 言外]）。

### 外报同行（路透/泰晤士渠道的编译记者）
- 说话：洋腔，爱引英/美报；把"悬疑"当卖点；
- 知道：NYT 11-16 电文与泰晤士驻京电 [U06][U07]、保皇党骂阵 [U04]；
- 拒绝：接受"京内没结论"；把一切引向"arguments without facts"。

### 史先生（报馆资料房掌档人，女性；行内尊称"先生"）
- 说话：简、冷、准；爱说"卷宗没有"；是后期的另一面镜子；
- 职能：帮你调档案 [整个证据库]、替你**对稿**（=质询：你的稿子
  里哪一处没落 [id]，她打问号）；
- 拒绝：立场。她永远先问"你在哪一页看到的"。
- 人设篮子：家藏几册书，阅旧抄本为乐；“版面要的是人味，卷宗有的是骨”
  （她的口头禅，也只能到此为止）。

## 四、幕次与任务（五幕 + 发稿）

### 序 · 一封匿名信
- 背景交代：报馆、奉安、匿名信一行字。
- 首个互动（按钮代替键入）：三个初始线头，任选其一开场
  （图书馆/实录馆档房/外报编译处）——不同选择会改变第二幕
  第一个 NPC 是谁（重玩性）。

### 第一幕 · 廿一小时（约 10′）
- NPC 一：内务府旧人 / 或 先访外报同行（按序选择分岔）。
- **T1 两副面孔**：把"三十四年无疾病"[V01] 与 脉案恶化链条 [D09]
  各自对着谁的耳朵说的，摆成两栏；
- **T2 排时序**：六事件卡拖入右栏（同前 v3），NPC 对稿，史先生复盘。

### 第二幕 · 贺寿那十天（约 12′）
- NPC 二+三：恽毓鼎（主）+ 杜钟骏（客）；
- **T3 喜色立场**（二选一）：这张选择像第一版的"壹"章，但贴着
  "信那张嘴还是信这个字"的戏演；
- **隐藏卡·壹：**"我不能先爾死"[E04] ——恽毓鼎开口条件=玩家先
  在 T3 表态；
- **隐藏卡·贰：**"塌喇"[D06]——向杜钟骏追问"临终帝吃着什么"才触发，
  以"太医院同僚"口径呈现（仅闻，加 L3 章）。

### 第三幕 · 街面上的三件事（约 8′）
- NPC 四：老太监 + 内务府旧人（补场）；
- **T4 三传闻贴签**（V03/G01/U07，annotation 表）；
- **T5 四证质辩**（茶馆圆桌戏）：四说各派一位"代言"（自由
  组合自 NPC 台词），玩家选"最致命破绽"（复用前版对质章）。

### 第四幕 · 隔世匣（约 6′）
- **明框跳帧**：史先生从柜顶取下一只上锁的黑匣——
  "这些不是你们的世界的东西。念之前，你把 1913 这年先摘掉。"
- 屋内烛光暗一拍（CSS 转场），匣内三张卡：[U09]1980 清理、
  [D10][D11][D12] 2008 检验、2404 数字动效；
- **边界题**（自由应答→对稿）：报告证明了哪一句？没证明哪一句？

### 终幕 · 发稿（约 7′）
- 案卷五选一（四说 + 新说）+ 一句话"社论"理由（可公开）；
- verdict 入库 → **"历届来稿"墙**（上一批玩家的分布）；
- 收束词：**"稿子见报，卷宗合上——可是卷子后面，时代还在出版。"**

## 五、隐藏卡与解锁树（汇总）

```
知情卡 "我不能先爾死"[E04]   ← T3 表态后由恽毓鼎出示
知情卡 "塌喇"[D06]           ← 向杜钟骏主动追问饮食
徽记 "卷宗精细"            ← 6 组矛盾对至此全部被玩家亲手触及
（触达 = 排序对证过 / 对质过 / 贴签质疑过 至少其一）
```

## 六、writing 规矩（不可让步；给实现者与 AI）

1. NPC 引证必带 [id] 角标；神态/称呼/语调可演，**史实不可编**；
   缺数据一律"卷宗没有，我不知道。"
2. L3 证词恒挂"仅见转述"章。
3. **道具级虚构清单**（允许且仅允许这些）：匿名信、案卷编号、
   茶馆桌号、报馆门牌、信纸样式、人物走位——全部不承载史实判断。
4. 年代纪律：任何 NPC（1913 在场者）**不得引用 1913 年之后出现的史料**
   （含 2008 报告、后来的学术论文）；科学检验只准通过"隔世匣"
   明框跳帧进入。
5. 玩家的采访本（本子内容=annotation/verdict 输入）永远显示
   "你写下的每个字都落在哪一行"。

## 七、实现映射（下轮改版）

- index.html → 场景状态机（序 + 五幕 + 终幕 = 7 screen；每屏内
  场景文/证据卡/任务面板/对话流四区）；
- 进度与解锁存 localStorage；server 不破坏 /api/ask·verdict·annotate，
  仅在 ask 的 prompt 注入"当前场景+NPC 人设"；
- skills 追加 `gamescript.md` 节（供 AI 演戏的 NPC 台词引擎用）；
- 音/动：翻纸声、更漏滴答、烛光暗场（CSS 级），零外部素材依赖。
