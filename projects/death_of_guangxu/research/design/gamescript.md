# Game Script 《廿一》 — 光绪之死 · 解密剧本（v1 蓝本）

## 一、形态与定位

- 类型：**单机线上剧本杀 / 解密游戏**（浏览器内玩，无真人主持人；
  主持人由"史官"承担——真 DeepSeek 驱动，职能＝法庭书记员+主审）。
- 时长目标：完整通关 **30–45 分钟**（demo 可切 10 分钟精简线）。
- 底层资产完全复用：55 行证据、6 组矛盾对、verdict/annotation 表、
  /api/ask 真模型质询——游戏只是在其上加**目标、状态、解锁规则**。

## 二、玩家角色

> **你是宣统三年（1911）实录馆新进的校录官。**
> 上头给的差事听着体面：为《德宗景皇帝实录》卷五百九十七的
> "大行皇帝驾崩一节"定稿。可你一进档房就发现：关于那天夜里的事，
> 档案们说的不是同一件事。
> 你的任务：让每一处矛盾要么被证据钉死、要么被如实记下"两说并存"，
> 最后在卷末写下一行**校语**——那是你的判决，将随实录传世。

（为什么选这个身份：误差最小——玩家干的每一件事，正是主持人
"摆证据、记矛盾"的方法本身；校录官对"谁下的毒"没有提审之权，
天然不许越界。）

## 四、幕次结构（五幕 + 终局）

### 第一幕 · 进档房（约 8 分钟）
- 场景：烛下摊开三样东西——脉案抄件、起居注散页、一份外报。
- **任务 T1（解锁）**：从卷宗中找出"两副面孔"——恽毓鼎的
  "三十四年无疾病"[V01] 对立面的三行 [D09][E01][G03]。
  答对 → 第二幕开；答错 → 史官质询一轮后放行。
- 隐藏卡（本幕埋）：**"我不能先爾死"[E04]** 只在玩家先选"喜色之谗"立场
  后由恽毓鼎"松口"才予出示（剧本杀里最值钱的钩子就是要兑换才能拿）。

### 第二幕 · 十九与廿一（约 15 分钟，核心幕）
- **任务 T2（排序）**：六事件卡（同 /api/ask 通道）排"你认为的当夜"。
  史官以库内行逐条质询——错误的卡会被指出与哪行 [id] 相撞。
- **任务 T3（对质）**：五证人轮番陈述（基于 §三 表），玩家每听完一人
  要给一个"信/疑"标注；标注会汇入 annotation 表（公众印象墙）。
- **隐藏卡（本幕埋）**：端出的"塌喇"[D06]——只有玩家在质询中主动问出
  "死前帝还吃过什么"，史官才肯出示。显现后自动挂出矛盾对 #4。

### 第三幕 · 身后诸说（约 7 分钟）
- 任务 T4（贴签）：三条传闻（V03/G01/U07）该入库哪条"采信、存疑、驳退"。
- 任务 T5（四说对质）：四个假说卡（依据行/破绽行），玩家选"最致命破绽"。

### 第四幕 · 百年定谳（约 5 分钟）
- **角色反转**：1980 与 2008 两份检验作为"最后两位证人"出场 [U09][D10][D11]。
- 任务 T6：报告边界题——报告证明了什么？没证明什么？（自由应答，
  史官依 [D10] 校准玩家话里的越界部分。）

### 终幕 · 校语（约 5 分钟）
- 玩家写下卷末校语：四说择一，或写新说（表单同现在）。
- verdict 入库后，展示"**历来校官的众校本**"（所有玩家的票的分布）——
  玩家的这行字成为下一位玩家头顶的陈列。
- 结局文案随选择变化（结局 A–E 各一段，§六）。

## 五、解锁与状态（前端 state 机）

- 进度存 localStorage（幕次/已收卡/已过任务），刷新不丢。
- 解锁树：T1 → 第二幕；T2 完成 → 五证人对质；"喜色"立场 OR 问出
  食物 → 隐藏卡×2；全 6 矛盾对被玩家至少触及一次 → 终幕加徽记
  "校录精细"（纯荣誉）。
- 计分：无扣分；唯"校语"质量是唯一成绩（终幕文案自评）。

## 六、结局文案（五案）

- A 慈禧说 / B 袁世凯说 / C 李莲英说 / D 病死说 / E 存疑自说：
  各写 60–90 字收束；共同落点：**"你的校语，已入卷——卷未终。"**

## 七、台词writing 规矩（不可让步）

1. NPC 句中**所有事实性引用必须带 [id]**（角标，同现 UI 规矩）。
2. 角色"神态/称呼/语调"可以虚构，**史实不得虚构**——缺的就说
  "档房里没有，我不知道"（这句将是史官最常说的台词）。
3. L3 证词一律加"仅见转述"小注。
4. 史官（她）负责质询与放行，**不替玩家推理**；她可以拒绝回答:
  "卷宗没有，问法不可。"
5. 隐藏卡的出示条件=玩家**主动发问或选择**，绝不自动弹出——
  这是"解密"而非"讲述"的关节。

## 八、实现映射（下次改版做）

- 前端由"线性页"改为**场景状态机**（每幕一屏：场景文+证据卡+
  任务面板+对话流），存储用 localStorage；
- server 不动（/api/ask 的 claim 字段天然承载玩家对白；新增
  `scene` 字段传入，供 prompt 注入"当幕的证人上下文"）；
- 史官 prompt 升级为"主审书记员"双职责，规则由 skills 渐进文件
  追加 `gamescript.md` 一节；
- 音效/转场动画：翻页纸声、烛光渐暗（CSS 即可，不引外部素材）。
