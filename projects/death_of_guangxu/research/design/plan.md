## M1 证据开采（本周）

产出：`sources/processed/records.json` 骨架（先 20 行）+
`research/notes/` 各源笔记。

- A. 把已到手两源的引文逐条抽成证据行（崇陵传信录约 15 条：十月初十贺寿
  事件、十九剃头、皇后见崩、李莲英草殓、流星、"六脉平和"、太后"我不能先
  尔死"……；戴逸文细读摘引文行）。
- B. 攻剩余瓶颈（**需要你举牌的一处**）：
  - 恽毓鼎《澄斋日记》：查学校图书馆有无浙江古籍 2004 本 / 电子库；
  - 《申报》1908-11 缩微或数据库访问权限；
  - 《逸经》第 29 期影印（屈桂庭《诊治光绪帝秘记》）。
  - **若 10/19 前拿不到**：降级策略——以 L2/L3 行为骨架、明确标 tier 和
    "未见原件"，交互文案如实说"此条我们只见到转述"。不装我有原件。
- C. 网取下一批：国闻备乘 / 十叶野闻 / 方家园杂咏纪事 / 清稗类钞 /
  实录卷 436 与三十四年十月条 / 钟里满报告尽量找公开版。
- D. 矛盾对逐条预登记（台账已列 5 组，开采中滚动增补）。

## M2 数据库合拢

- schema：`source / evidence / person / event / hypothesis /
  hypothesis_evidence / verdict`，每行 source+note，原名对照（繁简、年号
  日期换算规则写进 maintain 文件）。
- `records.json` 固化全部证据行（每行含 tier/stance/date/keyword/矛盾指向）。
- `build_db.py` 重建 + 抽查 20 行对回原文，错误记 journal。
- 判据：能跑出"按日聚合最后两周事件流"的一条真查询。

## M3 Skill 与检验

- `skills/verdict/`（名字再定）：`SKILL.md` 索引 + `answering.md`（只凭
  evidence 行、引用 [id]、矛盾必显式）+ `maintain.md`（加行步骤）+
  `principles.md`（"报告只给定死因不认凶手""假说≠结论""S 说不升 tier"）。
- rubric + 10 题库（含假前提题：如"光绪死于哪座坟"诱导；离题；"帮我
  从网上查"）。照 Week 4 流程跑分。

## M4 App 核心环

- `code/server.py`（Python 标准库既可，沿用 suiyuan 的骨架经验）+
  `static/index.html`。真 DeepSeek 调用：模型角色=审讯官，检索 evidence
  行注入 prompt，用户排序/假设被逐条用 [id] 质询；答不出就"库内无证"。
- 三幕最小可跑：展证（证据卡列表+矛盾高亮）→ 推演（拖拽排序+提交）→
  判决（提交 verdict 入库+分布图）。先丑后好。
- 判据：一次真实调用在 demo 网络下 <8s 返回，且可证明回答来自库（拔库
  就答不出——测试手段写进 journal）。

## M5 视觉层（可选裁剪区）

- 主意：证据卡用**原件扫描**做底（脉案手稿/报纸版面/恽录书影，能拿到
  什么用什么），泛黄纸纹+竖排引文+印章元素；配色一律在线稿级别先定。
- Blender（week 5 选做分支）：只预渲染"瀛台涵元殿"静帧 3–5 幅嵌入网页，
  证据不足处虚影/留灰并配脚注。时间若紧，M5 整体可降级为"档案图版
  +排版"即收工——**这是全计划唯一可整段裁剪的里程碑**。

## M6 检验与打磨

- 全题库跑分、修完崩溃、加载失败提示、无 key 时的降级提示（照 suiyuan
  做法，页面标明"规则模式"）。
- demo 剧本写进 `research/outputs/demo-script.md`：开场悬念（21 小时）→
  挑一张证据卡读原件 → 排序被追问一次 → 投一票看分布 → 结尾留白。
- README 终稿、journal 收尾、全库 commit 清点。

## 风险与既定对策

1. **拿不到原件**（最大）→ 不装。tier 照实、文案照实，正是课程想看的。
2. **UI 返工吃时间** → M5 是唯一可裁剪段，M1–M4 顺序铁律。
3. **版权**（《我的前半生》等）→ 只少行引证；扫描件不入 Git。
4. **纪律**：每里程碑完即 commit+push；journal 每工作日一行；
   我做每步都向你复述做了什么，你抽查再喊继续。
