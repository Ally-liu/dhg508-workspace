# Design: The Death of Guangxu (光绪之死)

## Project Title

- The Death of Guangxu (光绪之死) — 交互式证据探索

## Project Files

- [Research Journal](../journal/research_journal.md)

## Background and Context

1908 年 11 月 14 日，光绪帝崩于瀛台涵元殿，年仅 38 岁；次日慈禧太后亦崩。
一国之君与实际统治者相隔不足 24 小时先后离世，时人与后人疑窦从未平息：
官方脉案称久病虚劳，而恽毓鼎日记、西医诊断、造成"先帝暴崩"的传闻互相冲突。
2008 年，研究团队以法医毒理学手段检测光绪遗发与衣物，砷含量远超常人，
"急性砒霜中毒"几乎坐实，但**谁下的手**至今无定论——底层事实与上层归因
的割裂，正是本案最适合做成"证据审讯室"的原因。

## Research Questions

1. **史料层**：关于光绪之死前后约两周，存在哪些独立记载？各记载之间
   在哪些点上互相印证、在哪些点上互相矛盾？
2. **事实层**：现代检测（2008 砷含量研究）对死因给出了什么结论？
   其方法与证据强度如何？
3. **归因层**：各假说（久病而亡 / 慈禧授意 / 袁世凯恐惧报复 / 太监近侍）
   各自拥有哪些证据行支持、哪些证据行削弱？来源立场（官方/私人/外国/现代
   科学）如何影响证据权重？
4. **设计层**：如何把上述证据做成一个 three-act 交互（展证 → 推演 →
   判决），使模型的角色"只依据库内证据行追问"成为不可替代的核心环节？

## Scope

- **时间窗**：以 1908-10 至 1908-11 为主（病况恶化期 + 最后 24 小时），
  背景证据（脉案连续记录）可前溯但仍以该窗内的变化点为主。
- **人物**：光绪、慈禧、袁世凯、李莲英/近侍、 Dicey（西医）、恽毓鼎、
  陆润庠（御医）等直接见证或记载者；不下断语的事不写。
- **不涉及**：清宫秘闻式扩展（珍妃之死等只作为背景一行，不展开）。

## Methodology

- 证据开采：每条记录 = 一行，字段含 date、text、speaker/source_type、
  contradiction、source_id，全部指向 `sources/` 的原件或 processed 转写。
- 正史与私记并取：脉案与官方文书、恽毓鼎《澄斋日记》、西医 Dicey 记述、
  报刊（申报等）、2008 论文，标注每条的立场与可靠性。
- 交叉校验：同一事件的独立记载成对录入，矛盾点显式标注，供交互追问。
- 交互三幕：
  1. **展证**：证据卡（原件视觉）供浏览，含矛盾提示；
  2. **推演**：用户排时序/提死因，模型只依库内证据行追问"证据 [id] 与
     你的排序矛盾，你如何解释？"；
  3. **判决**：用户提交凶手判定及理由 → 存 SQLite `verdicts` 表，展示
     分布；页面呈现编辑部的加权假说评估（明确标注"这是编者评估"）。

### 可靠性分层

- 每条证据行标 `tier`：L1 原件/影印；L2 可靠转写/出版；L3 转述/二手。
- 每条证据行标 `stance`：official / private / foreign / press / science。

## Expected Outputs

- `artifacts/guangxu.db`：≥3 表（evidence / hypotheses / verdicts 等），
  ≥200 行，每行带 source 与 note。
- Web app：三幕交互页面 + 真 DeepSeek 交叉讯问模型。
- 渐进式 skill 一套。
- 展示性输出：时间线可视化、假说加权评估卡、（可选）Blender 静帧
  "瀛台涵元殿场景重建"，重建中不确定处以虚影/留灰表达。

## Working Hypotheses

- H1（久病而亡）：脉案连续记录虚痨重症，临终前病况恶化确有其记录。
- H2（慈禧授意）：时间紧邻（光绪先慈禧 20 余小时崩）、慈禧自感将不起时
  处置帝位的动机链、清宫权力结构独自形成闭环。
- H3（袁世凯恐惧报复）：戊戌旧怨+袁在帝崩前后处境与心态证据。
- H4（太监近侍）：与 H3 类似的动机链，但证据更薄弱。
- 每个假说维护：支持证据行列表、削弱证据行列表、支持者立场、置信度空缺，
  最终在网页上以"编者加权评估"呈现，并允许用户提交自己的判决入库。

## Risks and Open Questions

- 脉案、日记、申报报道**原件或可靠影印**是否可得？若只能取得二手转写，
  tier 必须如实标注且交互追问强度相应折损。**这是最大风险，优先解决。**
- 病案涉及医学史与毒理学：这些领域的二手文献质量参差，选择须审慎。
- 孤证不举：任何只被一种记载支持且无 corroborating 者的"明了事件"
  必须降级处理；宁缺毋滥。
- 单人项目工作量控制：三幕交互 + 数据库 + skill + server + 视觉，
  必须分阶段交付，先把证据库合拢再谈美学。
