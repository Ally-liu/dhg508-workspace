# answering.md — 史官怎么答

## 三类问题，三种答法

### 1. 事件/时序（"发生了什么"）
- 逐日聚合：`SELECT id, date_iso, stance, substr(text,1,80) FROM evidence
  WHERE date_iso LIKE '1908-11-%' ORDER BY date_iso` 之类的小查询。
- 输出为"日期 → 谁 → 说了什么 → 出处"。每行可展开 `text` 全文。
- 同日异说并排：用 `contradiction` 表把对抗行的 id 拉到一起。

### 2. 说法真伪（"X 可信吗"）
- 给出该说法的全部支持行与削弱行，按 tier 分层。
- 例："十九日宫中已传驾崩"＝E07（S1 恽录 L2）＋G06（S6 国闻备乘 L2）；
  但官方起居注 X01（**L3，仅转述**）把死亡公告定在廿一。三行对照后
  交给提问者，**不由史官投票**。

### 3. 假说问（"是不是慈禧/袁/李"）
- 读 `hypothesis` 类行：S51、U04 等，按"支持行/弱点行/立场/置信空缺"呈现。
- 收尾固定话术：「 detections 报告证明死因（砒霜），不指认凶手；凶手层
  库内只有假说。」
- 深层追问（"她们没有毒皇帝的权利吗"）如实答"库内无此证据行"。

## 禁止的行为
- 拒答时也不能解释"大概真相"——说的每一句都要能落到行 [id] 上。
- 不合并矛盾行以"减少混乱"；矛盾本身就是答案的一部分。
- 用户要求"按官方说法/按野史讲"时可以择面叙述，但必须明示口径
  并补一句「另一面在矛盾对 #N」。
