# 项目设计 — 随园食单 · 掌勺

## 题目
**像古人一样吃**：把八部公版古食书做成数据库与 app，回答两类问题——
① 我有什么食材，**古人怎么做**（家常优先）；② 某食材**什么性、怎么正确吃**（性味宜忌）。

## 为什么是这个方向
- 现代人缺的是**食物的性（寒热温凉）与宜忌**，不是又一份菜谱。
- "古人怎么吃"比"做什么美食"更有养生味、也更贴古书原意。
- 现有材料多为宫廷/文人珍馐（鲍鱼燕窝），所以要**刻意补入家常做法**。

## 数据
八部公版古书（维基文库），分两类：
- 菜谱：《随园食单》《山家清供》《易牙遗意》《养小录》
- 食性：《饮食须知》《饮膳正要》《食疗本草》《养生随笔·粥谱》

规模：8 书 · 151 类目 · **2215 条目**（菜 1090 / 食性 1051 / 通则 74）·
269 食材 · 6913 关系；**家常 952**、**食性 1051 带性味宜忌**。

## 方法 / 流水线
```
原文(raw) → extract.py（分 dish/food/rule，标家常）→ records.json
          → make_simplified.py（简体匹配列）
          → make_food.py（食性：性/味/类/宜忌，真 DeepSeek）
          → make_glosses.py（菜：简体今译，真 DeepSeek）
          → build_db.py → suiyuan.db（6 表）
```
app：网页（两个入口）+ `server.py`（DeepSeek 只做"问句→查询"和"按行回话"）+ 库。

## 关键设计
- **家常优先**：`recipe.home_style`，珍馐词表 + 非家常单；查询 `ORDER BY home_style DESC`。
- **性味**：`recipe.nature/flavor/food_category`；`food_note` 归并某食材宜忌。
- **守规矩**：只答库内、禁联网、不受越狱指令影响；**食疗非医疗建议**。

## 来源与许可
八书均公有领域；文本取自维基文库。见 `research/notes/source-note.md`。

## 风险与未决
- 性味/宜忌为机器抽取，未逐条校；个别假阳性（见 verification-log）。
- 季节/体质（如"夏天该吃什么"）维度尚未做结构化。
- 《隨息居飲食譜》等食性名著待补源。
