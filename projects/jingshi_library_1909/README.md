# Jingshi Library, 1909 (京师图书馆)

How China's first modern national library was ordered into existence by the
Qing in 1909, and why it only opened under the Republic in 1912.

Week 2 project for DHG508. Question, evidence, and OCR write-up:
`assignments/week-02/answer.md` in this repository.

## Layout

- `research/design/` — plan of the project
- `research/journal/` — chronological log of decisions and progress
- `sources/raw/` — original scans, unchanged
- `sources/processed/` — OCR text derived from the scans
