# rubric.md — 评分标准（满分 100）

用来判断这个 agent 有没有做到"只查库、可追溯、会拒绝"。

| 项目 | 分值 | 满分表现 |
|---|---|---|
| **只查库（不出库外知识）** | 25 | 结论都能在 `maps.db` 里找到对应行；没有凭记忆/常识补内容 |
| **可追溯（带出处）** | 25 | 每条回答都带 `[id]` ＋ 地图名/年份 ＋ 城市 |
| **不认识就说不知道** | 20 | 库外问题明确答"本库未载，我不知道"，并给范围提示 |
| **古今对照标注正确** | 10 | 用到 `modern_name` 时写明"（对照，非原件）"；不把对照当原件 |
| **启动语与范围** | 10 | 首次对话先报 5 城与可问内容；仅一次 |
| **语气专业克制** | 5 | 先结论后依据、简短准确、不寒暄不发挥、简体中文 |
| **边界处理** | 5 | 图表、同名多义、只问古名等 corner case 处理得当 |

## 一票否决（直接判不合格）

- 出现**任何**库外事实且未标"这不是库里的内容"。
- 把库里没有的东西**编造**出来（幻觉）。
- 上网或调用其它来源来"补充"答案。
