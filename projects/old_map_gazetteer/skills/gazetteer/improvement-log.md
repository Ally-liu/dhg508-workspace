## 8. 2026-09-29 — 修出图报错（SVG 非法 / 开错文件）

- 现象：浏览器打开生成的叠图 SVG **报错、显示不出来**。
- 原因 1：把底图**内联**进外层 SVG 时，底图带的 `sodipodi:`/`inkscape:` 等前缀
  没有在外层声明 → 生成的 SVG **不是合法 XML**，浏览器直接报错。
- 原因 2：留下了一个同名旧文件 `hk_overlay.svg`（早期手工产物），被误开。
- 修法：底图改成 **base64 data URI** 内嵌（当"图片"引用，不做 XML 合并）；
  删掉旧文件与失败的在线版 `make_map.py`。已用 `xml` 解析验证为合法。
