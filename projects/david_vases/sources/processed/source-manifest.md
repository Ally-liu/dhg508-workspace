# Source Manifest — 大维德花瓶（元至正十一年青花云龙纹象耳瓶）

每份资料的**原件**放 `sources/raw/`；本文件登记来源、许可与用途。

## 一手：藏品著录（核心依据）

- 大英博物馆藏品记录 **PDF,B.613**
  https://www.britishmuseum.org/collection/object/A_PDF-B-613
- 大英博物馆藏品记录 **PDF,B.614**
  https://www.britishmuseum.org/collection/object/A_PDF-B-614
  - 时代：元（Yuan dynasty）｜产地：景德镇｜制作年代：1351
  - 材质/技法：瓷，釉下青花（underglazed）；PDF B.613 另有刻（incised）
  - 尺寸：B.614 高 63.8cm、最大径 19.6cm、重 7.7kg；B.613 高 63.6cm、径 22.0cm
  - 纹样（著录）：铜器造型；象首双耳；器身**四爪云龙**（一开嘴一闭嘴）；
    缠枝牡丹 / 蕉叶 / 颈上部铭文；下部**飞凤**云纹；足部缠枝牡丹。
  - 铭文（原文）："信州路玉山縣順城鄉德教里荊塘社奉聖弟子張文進喜捨香炉花瓶一付
    祈保合家清吉子女平安至正十一年四月良辰謹記星源祖殿胡淨一元帥打供"
  - 递藏：Charles E. Russell 收藏（1935 经 Sotheby's，£360）／M.W. Elphinstone（1927）；
    Sir Percival David 收藏；2009 起借展大英博物馆；2024 正式捐赠。
- 九条装饰带（自上而下，据中文维基/研究者）：缠枝扁菊 → 蕉叶 → 飞凤灵芝 → 缠枝莲 →
  四爪云龙 → 海涛（2 层）→ 缠枝牡丹 → 覆莲杂宝（共 8 种题材）。
- 展厅 English 标签：Room 95, case 1；BBC *A History of the World in 100 Objects*。
